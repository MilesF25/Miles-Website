AGUMON, Making a LAN Server

Jul 12, 2026

A.G.U.M.O.N

Asynchronous Group User Messaging Over Networks

So this is a project i made cause im studying for my comptia sec+ exam and i was learning about databases and servers. The more I learn about cyber security I get more intrgiued on the low level things, like what does the code look like that lets firewalls block certain actions. Being a SOC analyst ## Reflection I built this project while studying for my CompTIA Security+ exam. As I learned more about databases and servers, I became more interested in the low-level side of cybersecurity. A SOC analyst needs to know how to use things like firewalls, but what really interested me was what the code behind them actually looks like. How does a firewall know what to block? How does a server handle multiple clients? This project was my attempt at understanding how servers are built and how they actually work. This project was hard. Diving into network programming with zero experience is not something I'd recommend. It is very different from regular programming, and trying to find resources on building a LAN server from scratch wasn't easy. On top of that, I was learning Rust features like `Arc`, `Mutex`, and multithreading at the same time. There were a lot of moments where I had to stop coding just to understand what was actually happening. My original plan was to have one person host the server and stream music to everyone who joined. The first roadblock was that I didn't really think through the structure of the program before I started coding. My first idea was to have the host start the server, run it, and manage everything from one console. That turned into a mess pretty quickly. I got overwhelmed trying to organize the code, so I stepped back and simplified everything. Instead of having a host manage the server, I made the server its own standalone program. The next hurdle was audio streaming. I wasn't able to implement it because it ended up being way more complicated than I expected. I still wanted to add something interesting, so I replaced the music feature with an AI chatbot. The chatbot joins the server using its own authentication token, and if someone mentions its name in the chat, it'll respond. Part of me is still disappointed that I couldn't get the audio streaming working. But for my first networking project, I'm willing to give myself a pass. I learned a lot about networking, concurrency, and planning software before writing code. I also realized how important a good architecture is. I think the rigid structure I started with is what held me back from implementing audio, but now I know what I'd do differently. Hopefully the next time I build something like this, I'll be able to design the server with more flexibility from the start. p>
